# Changelog

All notable changes to the reproducibility package are documented here.

## [1.0.0] - 2026-09-15

First publication-ready release candidate.

- Defines the C11 implementation as the computational reference.
- Retains the completed synthetic scientific-validation outputs.
- Retains the completed CPU/GPU publication benchmark outputs.
- Requires equivalence to the C reference before accepting timings.
- Separates compute and end-to-end timing regions.
- Restricts speedup comparisons to the same implementation family.
- Provides PDF-only publication figures and isolated figure smoke tests.
- Adds reviewer instructions, pinned direct dependencies, provenance records,
  release checksums, and Zenodo metadata.
